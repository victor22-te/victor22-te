### 🔬 Proyectos Destacados

- 🫀 **[Lectura-ECG-STM32](https://github.com/victor22-te/Lectura-ECG-STM32):** Sistema profesional de monitoreo ECG en tiempo real usando STM32F401. Incluye filtrado digital (DSP) embebido y visualización en Python.
- ⚙️ **[embedded-systems-rtos-stm32](https://github.com/victor22-te/embedded-systems-rtos-stm32):** Portafolio de programación bare-metal en C para la familia STM32F4 (configuración de GPIOs, relojes PLL, interrupciones EXTI, USART).
- 🚁 **[Control-de-Alabeo-para-Dron](https://github.com/victor22-te/Control-de-Alabeo-para-Dron):** Sistema de control PID para estabilización del ángulo de alabeo de un cuadricóptero usando ESP32 y MPU6050, con GUI en tiempo real.
- 👁️ **[eye-tracking-mouse-control](https://github.com/victor22-te/eye-tracking-mouse-control):** Sistema de control de mouse utilizando visión artificial y seguimiento ocular con Python.
- 📦 **[Banda-Transportadora-VHDL](https://github.com/victor22-te/Banda-Transportadora-VHDL):** Sistema de clasificación de objetos con VHDL y visión artificial usando una red neuronal.
